=== 5. 核技巧：圆环数据在二维分不开，加一个特征 x₁² + x₂² 就是一个平面能分 ===

  加第三维 r² 后线性 SVM 1.000——三维里一个水平的平面就把内圈与外圈分开
  不显式升维、直接用 RBF 核的 SVM 1.000（核函数在算「升维后的内积」，但从不真的构造那些特征）

=== 6. RBF 核：K(x, x') = exp(−γ||x − x'||²)；γ 大 = 每个点的影响范围小 = 边界更弯 ===
  γ = 0.1 : 训练 0.870 / 测试 0.885，支持向量 92 个
  γ = 1   : 训练 0.940 / 测试 0.935，支持向量 54 个
  γ = 200 : 训练 1.000 / 测试 0.865，支持向量 190 个
  图已保存 out/05-rbf-gamma.svg
  γ 太大 → 每个训练点周围一个小岛，训练 100% 测试掉——又是过拟合；γ 与 C 一起用验证集选

=== 7. 核 = 相似度加权：核回归的公式与 attention 的公式是同一个 ===
  RBF 核回归与用点积 + softmax 写的 attention，在 200 个查询点上的最大差 1.0e-15
  图已保存 out/05-kernel-regression-attention.svg
  attention(Q, K, V) = softmax(QKᵀ/√d) V：相似度（点积核）→ 归一化 → 加权值。区别是 Q、K、V 都是学出来的投影

=== 9. 从原问题到对偶：w = Σ αᵢyᵢxᵢ，训练与预测只用到样本两两的内积 ===
  第 1 节那 60 个点：支持向量 [[-0.978, -0.117], [-0.541, 0.82]]，系数 αᵢyᵢ = [-1.872, 1.872]
  w = Σ αᵢyᵢxᵢ = [0.819 1.753]；sklearn 的 coef_ = [0.819 1.753]；最大差 0.0e+00
  两个支持向量的 αᵢyᵢ 大小相等符号相反（Σ αᵢyᵢ = 0.0e+00），所以 w 平行于两点的连线 x₊ − x₋ = [0.437 0.936]
  第 3 节的 1000 个样本：原问题 SGD 的 w 与核化版还原的 Σ αᵢyᵢxᵢ 最大差 3.3e-16，300 个测试点决策值最大差 2.4e-15
  核化版只存 α（700 个数），其中 609 个非零——这些就是训练中至少一次间隔不足 1 的点；其余 91 个点从未进入 w
  同一段代码、把 K = XXᵀ 换成 RBF 核矩阵（C′ = 100，即 C_sum = 100/300）：圆环数据训练准确率 1.000，非零 α 199 个；sklearn SVC(rbf, C=100/n) 支持向量 76 个、准确率 1.000
  代码里从头到尾没有出现 φ(x)：升维只发生在「K 是某个 φ 的内积」这个事实里，算法只看 K

=== 10. C 的尺度：½||w||² + C·Σ hinge（LinearSVC/SVC）vs ½||w||² + C'·mean hinge（手写 SGD）vs λ/2·||w||² + mean hinge（SGDClassifier）===
  n = 700。三种写法同一个最优解的换算：C_sum = C'/n，λ = 1/(n·C_sum) = 1/C'
     手写 C′   ||w|| 手写  LinearSVC(C′/n)     余弦  LinearSVC(C′)     余弦  SGD(α=1/C′)     余弦
      0.01      0.010            0.010  1.000          1.130  0.976        0.010  1.000
         1      0.615            0.617  1.000          2.362  0.977        0.619  1.000
       100      2.604            2.007  0.966          2.471  0.967        2.012  0.973
  C′ = 1 时按「求和」目标 ½||w||² + (1/n)·Σ hinge 打分：手写解 0.6354，LinearSVC(C=1/n) 的解 0.6359（同一个目标，后者是精确求解器）
  把训练集复制 1 份（n = 700）、C_sum 固定 0.01：||w|| = 1.130，间隔 0.885——按求和的 C 随 n 变大等于正则在变弱
  把训练集复制 2 份（n = 1400）、C_sum 固定 0.01：||w|| = 1.364，间隔 0.733——按求和的 C 随 n 变大等于正则在变弱
  把训练集复制 4 份（n = 2800）、C_sum 固定 0.01：||w|| = 1.584，间隔 0.631——按求和的 C 随 n 变大等于正则在变弱
  所以换数据量、换库、换论文时先问一句：它的 C 乘的是 Σ 还是 mean？差的那个 n 就是正则强度差的倍数

=== 12. attention 与核平滑：三步公式一样；相似度是不是核、有没有「训练集」，不一样 ===
  40 个 8 维点的 RBF 核矩阵：对称 True，最小特征值 5.26e-01（≥ 0：是一个合法的核 / 内积）
  attention 的打分 S = (XW_Q)(XW_K)ᵀ/√d，W_Q ≠ W_K：|S − Sᵀ| 最大 5.67（不对称：i 看 j 与 j 看 i 不一样），对称部分最小特征值 -14.15（< 0：不是任何 φ 的内积）
  若令 W_K = W_Q：对称 True，最小特征值 -7.35e-15——这时 exp(S) 才是一个核（exp 保持半正定），类比才能下到「核」这一层
  但第三步一样：两者的权重矩阵每行和都是 1（attention 1.000–1.000，核回归 1.000–1.000），输出都是「值」的凸组合
  参数：核回归 0 个可学参数（只有 γ）、键是训练集本身（n = 40 行要存下来）；attention 这一层 3 个 8×8 矩阵共 192 个参数，键是同一次前向里的输入，不是训练集
  所以类比成立在「相似度 → 归一化 → 加权值」这一层；「相似度是核」只在 Q、K 共享投影时成立；「它是 SVM」不成立——没有间隔目标、没有逐样本的 α
