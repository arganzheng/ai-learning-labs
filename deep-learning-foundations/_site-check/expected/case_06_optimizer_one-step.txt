一个标量参数 theta=1.0，梯度序列 [0.5, 0.5, -0.1, 0.4]，lr 0.1，beta1 0.9，beta2 0.999，lambda 0.1，eps 1e-08

== 第 1 步（g = 0.5）==
  SGD      : dθ = -lr·g            = -0.0500   θ -> 0.9500
  Momentum : m = b1·m0 + g = 0.5000，dθ = -lr·m = -0.0500   θ -> 0.9500
  Adam     : m = (1-b1)g = 0.0500，v = (1-b2)g^2 = 2.50e-04
             m_hat = g = 0.5000，v_hat = g^2 = 0.2500，dθ = -lr·g/|g| = -0.1000   θ -> 0.9000
  AdamW    : Adam 项 -0.1000 + wd 支路 -lr·λ·θ = -0.0100，dθ = -0.1100   θ -> 0.8900
  对照：无偏差修正的 Adam 第 1 步 dθ = -lr·(1-b1)/sqrt(1-b2)·sign(g) = -0.3162（3.16 倍）

  Momentum:

  读法：第 1 步 |dθ| = lr（0.1000 ≈ 0.1）与 g 的大小无关——偏差修正让 m_hat=g、v_hat=g^2，归一化直接把步长顶满；这就是大学习率下 warmup 几乎不能省的原因。
