=== LeNet-5 复现（mps）===
  逐层形状与参数量：
    输入                     → (1, 28, 28)    
    C1 卷积 5×5, 1→6         → (6, 28, 28)    参数 156
    S2 池化 2×2              → (6, 14, 14)    
    C3 卷积 5×5, 6→16        → (16, 10, 10)   参数 2,416
    S4 池化 2×2              → (16, 5, 5)     
    拉平                     → (400,)         
    C5 全连接 400→120         → (120,)         参数 48,120
    F6 全连接 120→84          → (84,)          参数 10,164
    输出 84→10               → (10,)          参数 850
  共 61,706 个参数（第一篇的两层 MLP 是 203,530——LeNet-5 用 1/3 的参数）；两个卷积层只有 2,572 个参数，96% 的参数在三个全连接层
  epoch 1  train loss 0.7333  test acc 97.10%  (4s)
  epoch 2  train loss 0.0883  test acc 98.04%  (6s)
  epoch 3  train loss 0.0483  test acc 98.85%  (7s)
  epoch 4  train loss 0.0304  test acc 99.15%  (9s)
  epoch 5  train loss 0.0189  test acc 99.18%  (10s)
  测试集错 82 张（0.82%）；LeCun 等 1998 报的 LeNet-5 是 0.95%（他们训了 20 个 epoch、有数据增强的版本 0.8%）
  对照同一份 MNIST：KNN 2.95%（L2 第四篇）、RBF-SVM 1.43%（L2 第五篇）、两层 MLP 2.39%（第一篇）、LeNet-5 0.82%——参数是 MLP 的 1/3，错误率降到 1/3。卷积赢在两处：每个 5×5 的核在整张图上共享，同一个笔画特征在哪都认得；池化让它对几个像素的平移不敏感。
