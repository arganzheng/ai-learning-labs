== 1. 打分：不投影 vs 投影 ==
  不投影（W_Q = W_K = I）：行 = 谁在找（query），列 = 被找的（key）
    猫 → 猫:1  它:0
    它 → 猫:0  它:1
  投影后：行 = 谁在找（query），列 = 被找的（key）
    猫 → 猫:0  它:0
    它 → 猫:1  它:0
  M = W_Q W_K^T = [[0.0, 0.0], [1.0, 0.0]] 是否对称: False

== 2. W_O ==
  拼接 o = [1, 2, 3, -1]
  o¹ W_O¹ = [1, 2, 1, 0]  o² W_O² = [-1, 0, 3, 3]
  o W_O = [0, 2, 4, 3] = 两项之和: True
  不经 W_O 直接加回: x + o = [2, 2, 5, 0]
  经 W_O 加回:     h = x + o W_O = [1, 2, 6, 4]

== 3. 把每个头的 W_V^i W_O^i 合成一个 d×d 矩阵（Llama-3-8B 一层，按 32 个 query 头算）==
  分开存：32 × (4096×128 + 128×4096) = 33.6 M
  合成存：32 × 4096×4096           = 536.9 M（16 倍）
