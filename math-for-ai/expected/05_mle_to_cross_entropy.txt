======== 为什么取对数：1000 个 0.01 相乘 ========
  直接相乘（float64）：0.0   ← 已经是 0，信息全丢
  log 求和：1000 × log(0.01) = -4605.2   ← 正常的数
  float64 能表示的最小正数约 2.2e-308，0.01^1000 = 1e-2000 远小于它
  单调性：p 越大，log p 越大： 0.9→-0.11 0.5→-0.69 0.1→-2.30 0.01→-4.61 0.001→-6.91

======== softmax：手算 vs PyTorch；三条性质；溢出 ========
  logits [2.0, 1.0, 0.0] → e^z [7.389, 2.718, 1.0] 和 11.107 → p [0.665, 0.245, 0.09]
  torch.softmax 给的：[0.665, 0.245, 0.09]
  真实 token 是第 2 个：手算 −log p₂ = 1.4076；F.cross_entropy(z, y) = 1.4076
  保序：p 的排序 [0, 1, 2] = logits 的排序 [0, 1, 2]
  差值决定比值：p₁/p₂ = 2.718 = e^(2−1) = 2.718；p₁/p₃ = 7.389 = e² = 7.389
  平移不变：softmax(z + 100) = [0.665, 0.245, 0.09]
  溢出：直接算 e^[1000.0, 1001.0, 999.0] = [inf, inf, inf] → p = [nan, nan, nan]
  先减最大值 1001：e^(z−m) = [0.368, 1.0, 0.135] → p = [0.245, 0.665, 0.09]
