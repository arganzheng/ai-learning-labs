======== 策略梯度：10 个 token 的策略，奖励 = 偶数得 1 ========
  初始均匀策略：J = E[R] = 0.50；精确梯度 ∂J/∂z = [0.05, -0.05, 0.05, -0.05, 0.05, -0.05, 0.05, -0.05, 0.05, -0.05]
  读法：偶数 token 的 logit 该增加（+0.05），奇数的该减少（-0.05）——梯度 = π_k (R_k − J)：比平均好的往上、比平均差的往下

  每次估计采 n = 4 条回答，重复 20000 次，看 ∂J/∂z₀（token 0，偶数）这一个分量：精确值 0.0500
  方法                                  估计的均值      标准差
  REINFORCE（b = 0）                   0.0511   0.1443
  baseline b = 0.5（= 平均奖励）           0.0503   0.0701
  离谱的 baseline b = −5                0.0543   0.8979
  GRPO：b = 组内均值（含自己）                 0.0374   0.0630
  RLOO：b = 其余几条的均值                   0.0505   0.0850
  → 前三种均值都 ≈ 精确值（无偏），标准差：好 baseline 最小、离谱 baseline 反而比不减更大；GRPO 均值缩成 (1 − 1/n) = 0.75 倍（有偏），RLOO 无偏

  GRPO 偏差的精确验证（G = 2，枚举全部 100 种采样组合）：
    精确梯度 ∂J/∂z₀ = 0.0500；GRPO 估计的期望 = 0.0250 = 0.50 × 精确值；RLOO 估计的期望 = 0.0500

  训练 300 步（G = 4，lr = 0.5，20 个种子），P(偶数) 从 0.50 出发：
    REINFORCE，奖励 0 / 1                   300 步后均值 0.991，最差种子 0.984，0 个种子坍缩到奇数 token，到 0.9 平均 55 步（没到的按 300 算）
    REINFORCE，奖励 10 / 11                 300 步后均值 0.650，最差种子 0.000，7 个种子坍缩到奇数 token，到 0.9 平均 94 步（没到的按 300 算）
    减组内均值（奖励 10 / 11，与 0 / 1 一样）         300 步后均值 0.980，最差种子 0.973，0 个种子坍缩到奇数 token，到 0.9 平均 86 步（没到的按 300 算）
    GRPO：再除以组内 std                       300 步后均值 0.994，最差种子 0.987，0 个种子坍缩到奇数 token，到 0.9 平均 38 步（没到的按 300 算）
  → 奖励是 0/1 时不减 baseline 也能学（采到奇数不推、采到偶数推高）；奖励整体抬到 10/11，不减 baseline 就出事——每条采到的回答都被「奖励 10」猛推，前几步碰巧多采了哪个 token 就把概率全押上去，押到奇数就再也学不回来；减了均值就与抬不抬无关
