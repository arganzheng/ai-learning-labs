=== 1. VQ tokenizer：2×2 patch（4 个数）→ 码本里最近的码字的编号 ===
  码本 K = 32（5 bit / token）；一张图 = 16 个 token = 80 bit，原图 64 像素 × 4 bit = 256 bit
  第 0 张图（数字 0）的 token 序列：[3, 17, 0, 29, 9, 16, 14, 1, 25, 10, 18, 1, 3, 28, 4, 3]
  重建 MSE 0.0086；码字使用次数最多 9399、最少 267——0 个死码字
  K =   8：重建 MSE 0.0247——码本越大重建越好，但 AR 模型要在越多的类里选
  K = 128：重建 MSE 0.0034——码本越大重建越好，但 AR 模型要在越多的类里选
  图已保存 out/09-vq-tokens.svg

=== 2. FSQ：不学码本，每一维独立 round 到 L 个刻度 ===
  L = 4，4 维：隐式码本 4^4 = 256 个码字，无需训练；用到 245 个；重建 MSE 0.0043
  第 0 张图第 5 个 patch：像素 [0.94 0.12 0.75 0.  ] → round 到 [1.         0.         0.66666667 0.        ] → 编号 35

=== 3. 自回归生成：按栅格顺序，next-token 的条件是「左边的 token 与上边的 token」，用计数表估概率 ===
  训练序列的平均对数似然 -22.58（每 token -1.41，即平均从约 4.1 个候选里选）；随机猜是每 token log(1/32) = -3.47
  生成一张图 = 16 次「查表 → 抽样」；一个 1024² 的图在 f16 下是 4096 次——这就是 AR 图像生成慢的原因
  图已保存 out/09-ar-samples.svg
